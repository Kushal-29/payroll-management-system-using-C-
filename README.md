🧾 Payroll Management System (C++)

A simple yet functional Employee Payroll Management System developed using C++, File Handling, and BGI Graphics (Turbo C++).
This project allows users to maintain employee records, calculate salaries, and manage payroll operations in a structured manner.
                         
🚀 Features           
✔️ Employee Management

Add new employee

Edit/modify existing employee

View all employee records

Auto-save all details in employee.txt

💰 Payroll Processing

Basic Pay calculation

DA (10% of BP)

HRA (15% of BP)

Gross Pay

PF deduction (12% of BP)

Professional Tax (₹200)

Final Net Salary

🔐 User Login System

Two user roles

Username + Password authentication

Basic security using getpass()

🎨 Graphics (Turbo C++ – BGI)

Custom UI interfaces

Buildings illustration

Ninja star animation

Welcome screen frame

Menu interface using outtextxy()

📁 File Handling

Save records

Load records

Update employee records

Persistent storage with .txt file

🏗️ Tech Stack

C++

Turbo C++ Compiler

BGI Graphics (graphics.h)

File Handling (fstream)

Console-based menu system

🔧 How to Run

Note: Works only in Turbo C++ / DOSBox environment because of BGI graphics.

Step 1: Install Turbo C++ or DOSBox
Step 2: Place project inside C:\TurboC3\BIN
Step 3: Ensure BGI folder exists at:
C:\TurboC3\BGI

Step 4: Compile & Run

Open Turbo C++

Load the .cpp file

Compile → Run (Ctrl + F9)
